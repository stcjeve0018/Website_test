# 電子抽獎系統

這個專案提供簡潔的電子抽獎頁面，可輸入參與者名單與獎項，並立即抽出中獎者，並記錄抽獎歷程。

## 使用方式
1. 於輸入框填入參與者名單，可使用逗號或換行分隔。
2. 填寫獎項名稱。
3. 點擊「開始抽獎」按鈕，即會顯示中獎者與抽獎紀錄。
4. 透過「清除」按鈕可重設輸入與結果。

## 開發筆記
- 前端使用 Bootstrap 5 提供版面與元件樣式。
- `script.js` 負責抽獎邏輯、動畫效果以及歷史紀錄。
- `styles.css` 包含抽獎卡片與結果區塊的客製化樣式。
